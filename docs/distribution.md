# Distribution Checklist (earned, not spammed)

> One substantial, evidence-based resource every ~2 weeks. Adapt each to the
> venue; never cross-post identical text or drop irrelevant links.

## Assets ready to distribute

1. **Shopify click-to-sale tutorial** → `/integrations/shopify` +
   `/features/conversion-tracking` + working sample payload.
2. **Slugy vs Dub (verified 2026-10-09)** → `/blogs/slugy-vs-dub` with live
   Dub Links pricing figures and honest tradeoffs.
3. **UTM → short link → conversion workflow** → `/tools/utm-builder` +
   `/blogs/lead-conversion-tracking` joined into one tutorial.
4. **Self-hosting guide** → `docs/self-hosting.md` for Show HN / DEV.

## Venues (participate, don't broadcast)

| Venue                        | Angle                                         | Success signal                                         |
| ---------------------------- | --------------------------------------------- | ------------------------------------------------------ |
| Hacker News (Show HN)        | Real demo + architecture + limitations        | Reproductions, trial activations, substantive critique |
| DEV Community                | Working click-ID/lead/sale code sample        | Guide → signup + repo referrals                        |
| Reddit (relevant subs only)  | Answer a real tracking question first         | Helpful replies, requested links, activations          |
| Indie Hackers                | Lessons from building analytics / first users | Founders testing campaign tracking                     |
| Product Hunt                 | Distinctive working attribution flow          | Activated users + feedback, not upvotes                |
| OpenAlternative              | Refresh claims, screenshots, links            | Referral clicks + activated users                      |
| Curated GitHub awesome-lists | Submit only where criteria truly match        | Referring traffic + independent installs               |

## Rules

- No automated directory spam, link exchanges, or purchased backlinks.
- No scripts, paid reviews, or manufactured testimonials — ask real users to
  share independent experiences, in their own words.
- Every comparison claim ships with a checked date and live source.
- Track referral → signup → activation per venue; double down only on what
  produces activated users, not clicks.
